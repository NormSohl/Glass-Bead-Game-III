# Seq

**Work in progress, not ready for release.** Seq is not on the App Store, and
Glass Bead Game III ships without it. Expect rough edges and changes.

Seq is a companion app for GBG III, for macOS and iPadOS: a piano-roll
editor for writing sequences note by note, and for capturing, reviewing and
editing performances played in GBG III over MIDI.

It builds from the same Xcode project (`Glass Bead Game III.xcodeproj`,
scheme **Seq**) and shares the `GBGCore` and `GBGSound` packages with GBG III.
The draft manual is [docs/seq-manual.md](../docs/seq-manual.md).
